## Why the slide decks are not committed
- The Week 4 deck contains the class API key, and the assignment says keys must never be on GitHub.
- The decks are large (Week 6 is over GitHub's 50 MB warning size).

Each teammate downloads the decks from Canvas and puts them in a local `materials/` folder, which git ignores. Users add files to the app through its upload control.
